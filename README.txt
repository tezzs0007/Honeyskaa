HONEYSKA — BATMAN WEBSITE
============================

Open index.html in a browser.

Files:
- index.html
- photos/        (54 extracted photos)
- audio/Kaadhal Aasai.mp3
- audio/Maula Mere.mp3
- eyes.jpg

The site is designed mobile-first for iPhone portrait.

Unlock flow:
1. Welcome
2. Name = Batman
3. Birthday = 13/10/2008
4. 5-question quiz
5. ACCESS GRANTED
6. Letter + slow blurred Polaroid background
7. 3 taps on a floating 🧿 reveals the eyes image
8. Final nickname answer opens WhatsApp to the configured number

Note: Browsers commonly block autoplay until the visitor interacts with the page. The music therefore attempts to start after interaction and continues once permitted.
